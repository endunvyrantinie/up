## 🚀 How to Use:

### **1. Access Admin Panel:**
- Go to: `yourwebsite.com/admin`
- Login with admin credentials
- Full control of everything

### **2. Customize QR Codes:**
- Go to Admin Panel → Settings
- Scroll to "QR Code Settings"
- Change:
  - QR code data format
  - Colors
  - Size
- Click "Save Settings"

### **3. Manage Users:**
- Go to Admin Panel → Users
- View all users
- Adjust balances
- Add bulk bonuses

### **4. Manage Transactions:**
- Go to Admin Panel → Transactions
- View all transactions
- Approve withdrawals
- Export data
